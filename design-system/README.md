# AD·OS — design system

The design language for orchimada.github.io. One system, two tones: **CONCEPT**
(figure forward, sells) and **DEEPTECH** (ground exposed, explains). Motif: the
dot field. One paint: signal red.

```
design-system/
├── GUIDELINES.md      the idea, constraints, voice, tones, tokens, vocabulary
├── references.md      what was taken from Stripe / Nothing / Teenage Engineering
├── styles/
│   ├── system.css     tokens + components (single source of truth)
│   └── system.js      dot grille, mode switch, filters, readouts
└── examples/
    ├── main.html      business page — CONCEPT home
    └── skill.html     engineering page — DEEPTECH home
```

Start at [`GUIDELINES.md`](GUIDELINES.md). Earlier explorations are archived in
[`../design-system-concepts/`](../design-system-concepts/).
