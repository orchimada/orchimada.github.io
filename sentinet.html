Pet Project · macOS Network Monitor

Sentinet

See exactly what your apps — and your AI agents — send to the internet. A lightweight macOS monitor that shows who's talking to the network, where, and how much — and lets you cut off anything suspicious before the data leaves your machine.

Live demo ↗ ⬇ Single-file edition (35 KB)

Python 3 · no install, no dependencies, no root, no account · macOS only

Why it exists

You hand your AI agents access to your files, your tokens, your secrets. Do you actually know where they're sending it? Modern dev machines run dozens of processes that phone home constantly — and the one time an agent quietly ships an API key to an endpoint you never approved, you find out far too late.

Existing tools either drown you in raw packets or only tell you something connected. Sentinet is built to answer one question fast: "Is this normal, or should I block it?"

What it does

📡 Per-app traffic visibility

Every outbound connection mapped to the app that made it — process → host → volume. No more anonymous traffic.

⚡ Live bandwidth & speed

Instantly tell whether an app is eating your bandwidth or the network itself is the problem.

✂️ One-click blocking

Kill a suspicious request on the spot — without killing the whole app.

🚨 Heuristic leak alerts

Risky connections flagged by host, volume, and pattern — even when the payload is encrypted. Where traffic is readable, secrets like API keys and tokens trigger alerts.

The design principle
Honest by design. Much of modern traffic is TLS-encrypted and can't be read — so Sentinet doesn't pretend. Connections it can't decrypt are marked 🔒 content unavailable: you still see who, where, and how much, and you can still block. Where it can't see something, it tells you it can't — instead of pretending it can. We sell trust, so we don't overpromise.
Run it in 10 seconds

The passive edition is a single Python file — real capture, metadata-only, opens a live dashboard in your browser:

# download, then:
python3 sentinet-passive.py

No install, no dependencies, no proxy, no root. Stop with Ctrl+C.

Who it's for
  • Developers running AI agents (Claude Code, Cursor, autonomous scripts) who want to know what those agents send before it's gone.
  • Engineers debugging their own apps who need a clean map of every network call.
  • Anyone handling secrets who wants a kill switch for outbound traffic — without enterprise DLP overhead.
Status

An MVP under active validation — currently macOS-only, real-time-only (no history yet), with deeper payload inspection, channel diagnostics, and cross-platform support on the roadmap. Feedback welcome: @orchimada.
