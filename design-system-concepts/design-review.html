The site runs four unrelated visual languages across its pages. This document proposes a single design system, then differentiates each page type with one deliberate constraint — so a visitor can tell what kind of page they're on before reading a word. Two candidate systems below; pick a direction, and I'll roll it across every page.

01The proposal

Shared tokens. Per-type constraints.

One type scale, one spacing grid, one component kit — shared by every page. Then each page type gets a single rule that makes it instantly recognizable. The constraint is the brand: it forces consistency and creates variety.

TypePageThe constraint that defines it
SELFSelf-presentationThe cover. Biggest type on the site; the only page allowed a portrait and a full-bleed identity statement.
SKILLClaude skillMonospace-led spec. Fixed sections in fixed order (what · gates · install · try · verdict). Always a download + a code block.
WRITINGResearch / blogpostOne narrow reading column, nothing wider. Numbered sections, figures with captions, citations.
PRODUCTProduct / MVPHonest by design — no capability shown without its current limitation beside it. Always a status pill + a live link.
PLAINPlain infoMaximum legibility, zero ornament. No images, one column, machine- and ATS-readable.

04Read & decide

Which direction?

Both unify the site and both differentiate page types. They differ in what the brand says about you.

Variation A · Blueprint

The engineer who distills complexity

  • Distinctive — nobody else's CV looks like this
  • Reinforces the diagrams & “judgment” positioning
  • The teardown work already lives here natively
  • Riskier; reads as “quirky” to some recruiters
  • Mono-heavy — harder to keep readable at length
Variation B · Editorial

The premium, hireable product leader

  • Safe, timeless, reads senior at a glance
  • Easiest to keep readable across long pages
  • Accent-per-type scales to future page kinds
  • Less distinctive — close to many SaaS sites
  • Diagrams need restyling to fit the cleaner skin

My recommendation: a hybrid — Editorial (B) as the base skin for readability and seniority, keeping Blueprint's diagram language (A) as the house illustration style inside figures. Best of both: clean pages, distinctive graphics. But it's your brand — tell me which way to lean.

05Next steps
